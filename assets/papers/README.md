# PDF文件存放文件夹

这个文件夹用于存放论文的PDF文件，方便我提取预览图片。

## 使用方法

1. **将PDF文件放入此文件夹**
   - 文件夹路径：`assets/papers/`
   - 支持的文件格式：`.pdf`

2. **文件命名建议**
   - 使用有意义的文件名，例如：
     - `tutorial_large_language_vision_model.pdf`
     - `dive_dit_video_generation.pdf`
     - `lidar_nerf_novel_view.pdf`

3. **我如何访问**
   - 我可以读取此文件夹中的所有PDF文件
   - 可以提取其中的图片作为预览图
   - 可以分析PDF内容

4. **当前可用的PDF文件**
   - 暂无PDF文件

## 注意事项

- 请确保PDF文件没有密码保护
- 文件大小建议不超过50MB
- 支持多页PDF文件

## 示例

如果您有Tutorial文章的PDF，可以命名为：
`tutorial_large_language_vision_model.pdf`

然后我就可以：
1. 读取PDF文件
2. 提取第一张插图
3. 创建高质量的预览图片
4. 替换当前的占位符图片
